Documentação interativa dos endpoints

🔐 Auth

/api/auth
POST/api/auth/registerpúblico
Criar nova conta. Retorna user + JWT.
CampoTipoObrigatório
namestringsim
emailstringsim
passwordstringsim
phonestringnão
POST/api/auth/loginpúblico
Login com email + senha. Retorna user + JWT.
CampoTipoObrigatório
emailstringsim
passwordstringsim
GET/api/auth/me🔒 protegido
Dados do usuário autenticado.

📦 Products

/api/products
GET/api/productspúblico
Listar produtos disponíveis com filtros.
ParâmetroTipoDescrição
searchstringBusca textual (título + descrição)
categorystringFiltrar por categoria exata
min_pricenumberPreço mínimo por dia
max_pricenumberPreço máximo por dia
citystringFiltrar por cidade
GET/api/products/:idpúblico
Detalhes de um produto específico.
POST/api/products🔒 protegido
Criar novo anúncio.
CampoTipoObrigatório
titlestringsim
categorystringsim
price_per_daynumbersim
descriptionstringnão
deposit_amountnumbernão
citystringnão
statestringnão
latitudenumbernão
longitudenumbernão
GET/api/products/categories/listpúblico
Listar categorias disponíveis.

📅 Rentals

/api/rentals
GET/api/rentalspúblico
Listar todos os aluguéis.
GET/api/rentals/my🔒 protegido
Listar aluguéis do usuário logado.
POST/api/rentals🔒 protegido
Criar reserva (com Redis Lock + Escrow).
CampoTipoDescrição
product_iduuidID do produto
start_datedateYYYY-MM-DD
end_datedateYYYY-MM-DD
{
  "rental": { "id": "...", "total_price": "120.00" },
  "message": "Payment held in escrow. Confirm pickup to release to owner."
}
PATCH/api/rentals/:id/pickup🔒 protegido
Confirmar retirada do item.
PATCH/api/rentals/:id/return🔒 protegido
Confirmar devolução. Libera pagamento para o dono e atualiza status do produto.

⭐ Reviews

/api/reviews
POST/api/reviews🔒 protegido
Criar avaliação para aluguel concluído. A média do avaliado é recalculada automaticamente.
CampoTipoDescrição
rental_iduuidID do aluguel concluído
ratingnumber1 a 5
commentstringOpcional
GET/api/reviews/user/:userIdpúblico
Listar avaliações recebidas por um usuário.
GET/api/reviews/pending🔒 protegido
Aluguéis concluídos que ainda não foram avaliados pelo usuário logado.

👤 Users

/api/users
GET/api/users/:idpúblico
Dados públicos de um usuário.
PATCH/api/users/profile🔒 protegido
Atualizar nome, telefone e/ou avatar.
POST/api/users/kyc🔒 protegido
Enviar documento para verificação de identidade.
CampoTipo
documentstring
POST/api/users/generate-qr🔒 protegido
Gerar token criptográfico para confirmação presencial via QR Code.
CampoTipo
rental_iduuid
POST/api/users/validate-qr🔒 protegido
Validar token QR. Se pickup pendente → confirma pickup. Se pickup ok → confirma return + libera pagamento.
CampoTipo
rental_iduuid
tokenstring

🔑 Exemplo de Autenticação

Todos os endpoints protegidos exigem o header:

Authorization: Bearer <seu_token_jwt>

Exemplo completo com cURL:

# 1. Login
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@email.com","password":"123456"}'

# 2. Usar o token
curl http://localhost:3000/api/auth/me \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..."
